# InkDetail

> Explain every detail.

InkDetail is a platform for creating interactive visual guides.

Upload an image, add interactive points to specific parts, attach explanations and resources, and share the finished guide through a simple link.

## Core workflow

Upload → Mark → Explain → Publish → Share

## MVP

- Create guides
- Upload images
- Add and position hotspots
- Add text, images and links to hotspots
- Preview guides
- Publish guides
- Share public links
- Responsive public viewer

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
